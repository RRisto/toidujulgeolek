# TAI raw data — Phase 1 pull (2026-08-29)

## RTU011_consumption_by_age_sex_2014.csv
Source: TAI PxWeb, table RTU011 "Keskmine toidugruppide tarbimine päevas soo ja vanuse järgi" (average food-group consumption per day, by sex and age), from Eesti rahvastiku toitumise uuring 2014 (survey fielded 2013-2015, ~5000 participants aged 4mo-74y — this is Estonia's only full national dietary survey; the next wave is mid-collection April 2026-May 2027, so no newer data exists yet).
https://statistika.tai.ee/pxweb/et/Andmebaas/Andmebaas__05Uuringud__09RTU__a_Toidugrupid_paev/RTU011.px/

768 rows = 16 food groups x 3 sex categories (total/male/female) x 16 age bands (national total + 2-5,6-9,10-13,14-17,18-24,25-29,...,70-74), all in grams/day. This is the actual-consumption side of Section 5.2 in PLAN.md, and pairs with the population table in ../statistikaamet/population_by_age_sex_2026.csv (note: RTU age bands differ from RV021's — RTU uses 5-year-ish bands starting at 2-5, RV021 uses standard 5-year bands from 0; a crosswalk/regrouping will be needed in Phase 2/3).

Food groups (food_group_et column, Estonian, as published) — the 16 rows are a 2-level hierarchy: 6 top-level groups (Tärkliserikkad toidud [starchy foods: grains+potato], Puu- ja köögiviljad marjad [fruit+veg+berries], Piim ja piimatooted [dairy], Kala linnuliha muna liha... [fish+poultry+egg+meat], Lisatavad toidurasvad... [added fats+nuts+seeds+oilseeds], Suhkur magusad... [sugar/sweets/snacks]) each with 2-3 "..sub-group" rows prefixed with ".." that break the top-level total down further (e.g. bread vs porridge/rice/pasta vs potato under starchy foods). Do not sum sub-groups + top-level together — the top-level row is already the total.

## Validation cross-check (see PLAN.md Section 5.2 for how this feeds the model)
- Dairy: RTU 2014 national average = 300 g/day = 109.5 kg/year. Statistikaamet PM47 2024 "fresh products excl. cream" human consumption per capita = 107.9 kg/year — remarkably close given the 10-year gap, suggesting dairy consumption habits have been stable. Good validation point.
- Vegetables: RTU 2014 "..köögiviljad" = 137 g/day = 50.0 kg/year, notably LOWER than the ~78.7 kg/year implied by Statistikaamet's PM33 domestic-use-minus-loss balance for 2024. This isn't a data error — it's exactly the gap Section 5.5 of PLAN.md anticipated: the survey measures what people actually reported eating, while the supply-balance "domestic use minus recorded loss" still includes retail and household waste that never gets eaten. Treat RTU as the actual-intake number and the balance-sheet figure as apparent/available supply; the difference is itself a rough empirical estimate of retail+household waste for that category, worth comparing against the SEI 2021 waste study's numbers in Phase 3.

## Extraction method
Classic PxWeb UI (not a JSON REST API — see PHASE1_NOTES.md for why), automated via browser: selected all 16 food groups, all 3 sex categories, all 16 age bands, quantity=grams, then read the resulting HTML result table directly. Parsed programmatically (regex line parser) with 0 unmatched lines against the full raw table text (kept in this session's working notes, not duplicated here) — the food-group and sex/age labels serve as their own structural delimiters, so this was a clean, low-risk parse (unlike the Tabelraamat PDF extraction, which relied on a lossy PDF-to-text summarizer).
